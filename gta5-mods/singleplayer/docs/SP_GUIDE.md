# Guia Single Player — RealLife Access Mod

## Fluxo recomendado no jogo

1. Entre no **Modo História**.
2. Pressione **F8** → `Ativar modo acesso total` (para testar tudo).
3. Pressione **F7** → escolha um carro → Enter.
4. Pressione **F9** → escolha um edifício → Enter.
5. Vá até o marcador roxo da Secret Room (ou F9 → Secret Room).
6. Pressione **F6** e complete a missão.

## Missão Secret Room (passos)

1. **Começo** — marcador roxo perto da entrada (`127, -1297, 29`).
2. **Cartão** — vá ao FIB andar alto.
3. **Hack** — use `E` no painel.
4. **Secret Room** — volte à entrada e pressione `E`.
5. **Cofre** — colete a recompensa (`+$250.000` + Kuruma blindado).

## Acessos

| Tecla | Menu |
|---|---|
| F7 | Garagem vida real |
| F8 | Níveis / acesso total / zonas no mapa |
| F9 | Edifícios |
| F6 | Missão |
| E | Interagir |
| X | Sair do interior |

## Dica

Para jogar “no modo história” sem liberar tudo de uma vez:

1. Comece no nível 0.
2. Faça a missão F6 para subir o acesso.
3. Use F8 só quando quiser testar/debugar.
