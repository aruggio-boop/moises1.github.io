# GTA 5 Single Player — Mods de Carros, Acessos e Secret Room

Pacote para **GTA V Modo História (Single Player)** com:

- garagem de **carros da vida real**
- **acessos totais e restritos**
- **secret room** + missão
- **edifícios** com entradas liberadas/bloqueadas

## Requisitos

1. GTA V (Steam / Rockstar / Epic) — **Story Mode**
2. [ScriptHookV](http://www.dev-c.com/gtav/scripthookv/)
3. [ScriptHookVDotNet v3](https://github.com/scripthookvdotnet/scripthookvdotnet/releases)
4. [OpenIV](https://openiv.com/) (para addons de carros)
5. (Opcional) Menyoo para testes rápidos

> **Não use em GTA Online.** Risco de ban.

## O que está incluso

| Pasta | Função |
|---|---|
| `singleplayer/RealLifeAccessMod/` | Script C# (ScriptHookVDotNet) |
| `singleplayer/openiv/dlc_realife/` | Estrutura para addons de carros |
| `singleplayer/menyoo/` | Teleports e atalhos prontos |
| `singleplayer/docs/` | Guias de instalação e coords |

## Controles no jogo

| Tecla | Ação |
|---|---|
| `F7` | Abrir garagem de carros |
| `F8` | Menu de acessos / níveis |
| `F9` | Teleportar para zonas / edifícios |
| `E` perto do marcador | Entrar em edifício / secret room |
| `F6` | Iniciar / continuar missão da secret room |

## Níveis de acesso

| Nível | Nome | Libera |
|---|---|---|
| 0 | Público | Ruas e locais comuns |
| 1 | VIP | Telhados, helipontos civis |
| 2 | Segurança | Prédios privados, garagens |
| 3 | Operações | Base militar, hangares |
| 4 | Classificado | Secret room, vault, missão final |

## Aviso sobre carros reais

Os **modelos 3D** de marcas reais **não vêm no pacote** (direitos autorais).  
O script já traz nomes e fallbacks vanilla. Você pode:

1. usar só os fallbacks (funciona imediatamente), ou
2. instalar packs de carros no OpenIV e mapear no `Config.cs`.

Veja `INSTALL.md` para instalar tudo.
